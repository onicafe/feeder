# Feeder | Instagram Grid Preview

**Feeder** is a visual planning tool for Instagram. It allows users to preview how new images will look on their Instagram grid before posting, without requiring a login for the preview functionality.

## Features

-   **Live Instagram Preview**: Fetch the latest 9 posts from any public Instagram account to see your real grid.
-   **No Login Required**: Uses a custom backend scraper (Web Profile Info API) to fetch public data securely.
-   **Drag & Drop**: Upload local images and rearrange them with your existing posts to find the perfect aesthetic.
-   **Image Proxy**: bypasses Instagram's hotlink protection to ensure images always load.
-   **Dark/Light Mode**: Toggle between themes.
-   **Grid Ratios**: Support for 1:1 (Square) and 4:5 (Portrait) aspect ratios.

## Tech Stack

-   **Frontend**: Vanilla HTML/CSS/JS (Lightweight, no framework overhead).
-   **Backend**: Node.js / Express (Serverless-compatible).
-   **Deployment**: Vercel.

## Setup

1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm start` to launch the local server (Port 3005).
